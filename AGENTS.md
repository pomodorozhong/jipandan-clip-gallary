# Agent notes

Static viewer for the team's voice clips. Goals, data format and decisions: [docs/](docs/README.md).

Checks: `npm ci`, then `npm run check` and `npm test` (regression tests for the triage server in `tests/`). Preview with `npm run serve`. The local triage page for importing and publishing clips runs with `npm run triage`; see [docs/triage.md](docs/triage.md).
